# Nova OS

Nova OS ist ein modernes, modulares Betriebssystemprojekt mit Fokus auf:

- eigene Bootarchitektur
- eigener Kernel
- eigene Grafik-Engine
- adaptive Benutzeroberfläche
- lokale KI
- Datenschutz
- Performance
- langfristige Wartbarkeit
