# NPSPEC-STUDIO-GRAPH-FUNCTION-NODES-0001

**Status:** Angenommen

## Zweck
NovaLang-Funktionen im Graphen aufrufen und definieren.

## Festlegungen
- Funktionssignaturen bestimmen Ein-/Ausgänge, generische Parameter und Fehlerrückgaben.
- Reine Funktionen sind als Datenoperationen, effektbehaftete Funktionen als Kontrollflussoperationen sichtbar.
- Rekursion, Asynchronität und Abbruch folgen den NovaLang-Laufzeitregeln.
- Ein Funktionsknoten erhält keine Systemberechtigung allein durch seinen Namen.

## Ergebnis
Graph und NovaLang verwenden dieselben Funktionsverträge.
