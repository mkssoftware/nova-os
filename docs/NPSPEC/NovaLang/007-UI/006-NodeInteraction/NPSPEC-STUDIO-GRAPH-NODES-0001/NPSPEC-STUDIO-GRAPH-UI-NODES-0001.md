# NPSPEC-STUDIO-GRAPH-UI-NODES-0001

**Status:** Angenommen

## Zweck
Oberflächenereignisse, Zustände und Bindungen mit dem Graphen verbinden.

## Festlegungen
- UI-Ereignisse und Eigenschaftsänderungen werden durch typisierte Schnittstellen repräsentiert.
- Die deklarative .nui-Beschreibung bleibt semantisch an die NovaLang-UI-Deklaration gebunden.
- UI-Aktualisierungen erfolgen über den vorgesehenen UI-Ausführungskontext.
- UI-Knoten erhalten keine impliziten Dateisystem- oder Netzwerkrechte.

## Ergebnis
Oberfläche und Logik sind gekoppelt, ohne Sicherheitsschichten zu überspringen.
