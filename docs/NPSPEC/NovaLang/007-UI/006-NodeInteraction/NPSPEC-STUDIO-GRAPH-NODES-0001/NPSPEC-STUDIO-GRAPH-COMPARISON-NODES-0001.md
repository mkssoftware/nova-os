# NPSPEC-STUDIO-GRAPH-COMPARISON-NODES-0001

**Status:** Angenommen

## Zweck
Werte typsicher vergleichen.

## Festlegungen
- Gleichheit, Ungleichheit und Ordnungsvergleiche sind nach Typfähigkeit verfügbar.
- Textvergleiche müssen Kollation und Groß-/Kleinschreibung explizit bestimmen.
- Strukturelle und referenzielle Gleichheit sind getrennte Operationen.
- Vergleiche inkompatibler Typen ergeben einen Validierungsfehler.

## Ergebnis
Vergleiche liefern konsistente, typgeprüfte Ergebnisse.
