# NPSPEC-STUDIO-RIBBON-HOME-0001

**Status:** Angenommen

## Zweck
Zentrale, jederzeit erreichbare Standardbefehle.

## Festlegungen
- Gruppen: Zwischenablage, Verlauf, Navigation und Schnellaktionen.
- Befehle: Ausschneiden, Kopieren, Einfügen, Rückgängig, Wiederholen, Suchen und Befehlsuche.
- Nur zum aktiven Editor passende Befehle sind aktiv; unpassende bleiben sichtbar und eindeutig deaktiviert.

## Ergebnis
NPSPEC-STUDIO-RIBBON-HOME-0001 definiert die verbindliche Ribbon-Funktionalität für zentrale, jederzeit erreichbare Standardbefehle.
