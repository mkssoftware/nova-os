# NPSPEC-STUDIO-RIBBON-TOOLS-0001

**Status:** Angenommen

## Zweck
Werkzeuge und Studio-Konfiguration.

## Festlegungen
- Gruppen: Werkzeuge, Erweiterungen, Einstellungen und Diagnose.
- Befehle: Einstellungen, Tastenkürzel, Erweiterungen, Protokolle, Diagnose und Workspace-Import/-Export.
- Erweiterungen registrieren Befehle über geprüfte Schnittstellen und können keine Sicherheitsrichtlinien umgehen.

## Ergebnis
NPSPEC-STUDIO-RIBBON-TOOLS-0001 definiert die verbindliche Ribbon-Funktionalität für werkzeuge und Studio-Konfiguration.
