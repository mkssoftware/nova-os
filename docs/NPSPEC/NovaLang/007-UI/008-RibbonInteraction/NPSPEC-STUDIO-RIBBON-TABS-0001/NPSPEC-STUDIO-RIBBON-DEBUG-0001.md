# NPSPEC-STUDIO-RIBBON-DEBUG-0001

**Status:** Angenommen

## Zweck
Debugging von NovaLang und Logic Graph.

## Festlegungen
- Gruppen: Ausführung, Breakpoints, Inspektion und Trace.
- Befehle: Start, Pause, Fortsetzen, Schritt, Stopp, Breakpoint setzen, Watch hinzufügen und Execution Trace öffnen.
- Debugansichten zeigen nur Werte, für die die aktive Debugsitzung Zugriff besitzt; Beobachten erweitert keine Capabilities.

## Ergebnis
NPSPEC-STUDIO-RIBBON-DEBUG-0001 definiert die verbindliche Ribbon-Funktionalität für debugging von NovaLang und Logic Graph.
