# NPSPEC-STUDIO-RIBBON-VIEW-0001

**Status:** Angenommen

## Zweck
Steuerung von Darstellung und Arbeitsbereich.

## Festlegungen
- Gruppen: Fenster, Layout, Darstellung und Navigation.
- Befehle: Panels ein-/ausblenden, Zoom, Vollbild, Zen-Modus, Layout zurücksetzen und Ansichten wechseln.
- Ansichtsänderungen verändern keine Projektinhalte und werden pro Workspace gespeichert.

## Ergebnis
NPSPEC-STUDIO-RIBBON-VIEW-0001 definiert die verbindliche Ribbon-Funktionalität für steuerung von Darstellung und Arbeitsbereich.
