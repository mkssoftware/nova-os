# NPSPEC-STUDIO-RIBBON-CAPABILITIES-0001

**Status:** Angenommen

## Zweck
Auswahl und Verwaltung deklarierter Fähigkeiten.

## Festlegungen
- Gruppen: Katalog, Verbindungen, Rechte und Prüfung.
- Befehle: Capability suchen, in Graph einfügen, Ein-/Ausgaben prüfen, benötigte Rechte anzeigen und Nutzung analysieren.
- Custom-Skripte können Rechte nicht selbst anfordern; externe Zugriffe erfolgen ausschließlich über zugelassene Capability-Knoten.

## Ergebnis
NPSPEC-STUDIO-RIBBON-CAPABILITIES-0001 definiert die verbindliche Ribbon-Funktionalität für auswahl und Verwaltung deklarierter Fähigkeiten.
