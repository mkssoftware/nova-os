# NPSPEC-STUDIO-RIBBON-CONTEXT-SWITCHING-0001

**Status:** Angenommen

## Zweck
Vorhersehbarer Wechsel der Ribbon-Befehle bei Fokusänderungen.

## Festlegungen
- Der aktive Editor bestimmt den aktuellen Befehlskontext; der vom Nutzer gewählte Tab bleibt möglichst erhalten.
- Kontextuelle Tabs werden nur bei passenden Objekten eingeblendet und klar gekennzeichnet; Kontextwechsel verschieben keine bestehenden Standardtabs.
- Offene Menüs und laufende Eingaben werden nicht überraschend verworfen; Tastaturfokus und Editorzustand bleiben erhalten.

## Ergebnis
NPSPEC-STUDIO-RIBBON-CONTEXT-SWITCHING-0001 definiert die verbindliche Ribbon-Funktionalität für vorhersehbarer Wechsel der Ribbon-Befehle bei Fokusänderungen.
