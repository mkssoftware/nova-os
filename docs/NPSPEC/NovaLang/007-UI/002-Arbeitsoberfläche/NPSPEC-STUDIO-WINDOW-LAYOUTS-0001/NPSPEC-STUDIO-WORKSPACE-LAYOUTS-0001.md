# NPSPEC-STUDIO-WORKSPACE-LAYOUTS-0001

**Status:** Angenommen

## Zweck

Vordefinierte und benutzerdefinierte Arbeitsansichten.

## Festlegungen

- Das Studio bietet zweckorientierte Layouts für Code, UI-Design und Logic Graph.
- Benutzer können eigene Layouts speichern, auswählen und auf einen Standard zurücksetzen.
- Der Layoutwechsel erhält geöffnete Dokumente und ungespeicherte Inhalte.

## Ergebnis

NPSPEC-STUDIO-WORKSPACE-LAYOUTS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
