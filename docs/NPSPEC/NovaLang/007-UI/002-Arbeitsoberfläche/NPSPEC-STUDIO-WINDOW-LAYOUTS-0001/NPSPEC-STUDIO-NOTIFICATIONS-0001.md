# NPSPEC-STUDIO-NOTIFICATIONS-0001

**Status:** Angenommen

## Zweck

Nichtstörende Rückmeldung zu Studio-Ereignissen.

## Festlegungen

- Benachrichtigungen unterscheiden Information, Erfolg, Warnung und Fehler.
- Nichtkritische Meldungen unterbrechen die Bearbeitung nicht; kritische Entscheidungen verwenden Dialoge.
- Wichtige Meldungen sind zusätzlich in einer nachvollziehbaren Meldungs- oder Ausgabenansicht zugänglich.

## Ergebnis

NPSPEC-STUDIO-NOTIFICATIONS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
