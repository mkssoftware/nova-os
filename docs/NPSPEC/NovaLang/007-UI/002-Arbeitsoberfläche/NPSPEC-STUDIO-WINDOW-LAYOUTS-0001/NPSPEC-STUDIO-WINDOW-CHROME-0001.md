# NPSPEC-STUDIO-WINDOW-CHROME-0001

**Status:** Angenommen

## Zweck

Einheitliche äußere Fenstergestaltung.

## Festlegungen

- Fensterrahmen und Systemschaltflächen folgen dem NovaStudio-Dark-Design und den Plattformregeln.
- Verschieben, Größenänderung und Fensterzustände bleiben über Standard-Eingaben erreichbar.
- Dekoration darf Inhalte, Fokusindikatoren und Systemfunktionen nicht überlagern.

## Ergebnis

NPSPEC-STUDIO-WINDOW-CHROME-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
