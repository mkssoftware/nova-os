# NPSPEC-STUDIO-SPLITVIEW-0001

**Status:** Angenommen

## Zweck

Parallele Bearbeitung innerhalb der Dokumentfläche.

## Festlegungen

- Dokumente lassen sich horizontal oder vertikal in geteilten Ansichten darstellen.
- Teilansichten besitzen unabhängig steuerbaren Fokus und Scrollzustand.
- Das Schließen einer Teilansicht schließt nicht automatisch das zugrunde liegende Dokument.

## Ergebnis

NPSPEC-STUDIO-SPLITVIEW-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
