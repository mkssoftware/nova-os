# NPSPEC-STUDIO-FULLSCREEN-0001

**Status:** Angenommen

## Zweck

Ablenkungsarme Nutzung der gesamten Anzeige.

## Festlegungen

- Vollbild blendet die äußere Fensterdekoration aus und maximiert die nutzbare Studio-Fläche.
- Ein klarer Tastatur- oder Menüweg stellt den vorherigen Modus wieder her.
- Offene Dokumente, Docking-Zustände und Fokus bleiben beim Wechsel erhalten.

## Ergebnis

NPSPEC-STUDIO-FULLSCREEN-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
