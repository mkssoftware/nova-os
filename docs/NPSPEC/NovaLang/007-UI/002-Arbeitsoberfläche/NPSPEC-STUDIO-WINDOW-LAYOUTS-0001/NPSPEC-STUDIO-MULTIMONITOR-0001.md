# NPSPEC-STUDIO-MULTIMONITOR-0001

**Status:** Angenommen

## Zweck

Verteilung des Studios über mehrere Bildschirme.

## Festlegungen

- Haupt- und Werkzeugfenster können auf verschiedenen Monitoren platziert werden.
- Beim Trennen eines Monitors werden nicht erreichbare Fenster automatisch in sichtbare Bereiche verschoben.
- Unterschiedliche Auflösungen und DPI-Skalierungen werden pro Monitor berücksichtigt.

## Ergebnis

NPSPEC-STUDIO-MULTIMONITOR-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
