# NPSPEC-STUDIO-PANELS-0001

**Status:** Angenommen

## Zweck

Konsistentes Verhalten eingebetteter Bedienfelder.

## Festlegungen

- Panels verwenden gemeinsame Header-, Größen-, Scroll- und Zustandsregeln.
- Panel-Inhalte dürfen abhängig vom Kontext aktualisiert werden, ohne den aktiven Eingabefokus unbegründet zu entziehen.
- Mindestgrößen und sinnvolle Leerdarstellungen sind vorgesehen.

## Ergebnis

NPSPEC-STUDIO-PANELS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
