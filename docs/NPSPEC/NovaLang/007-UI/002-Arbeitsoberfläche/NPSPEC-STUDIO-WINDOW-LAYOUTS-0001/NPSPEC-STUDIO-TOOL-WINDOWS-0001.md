# NPSPEC-STUDIO-TOOL-WINDOWS-0001

**Status:** Angenommen

## Zweck

Verwaltung spezialisierter Werkzeugfenster.

## Festlegungen

- Explorer, Eigenschaften, Ausgabe, Fehlerliste und Logic-Graph-Werkzeuge nutzen ein einheitliches Tool-Window-Modell.
- Werkzeugfenster können sichtbar, verborgen, angeheftet oder angedockt sein.
- Werkzeugzustände werden unabhängig vom Dokumentinhalt verwaltet.

## Ergebnis

NPSPEC-STUDIO-TOOL-WINDOWS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
