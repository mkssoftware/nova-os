# NPSPEC-STUDIO-DOCKING-0001

**Status:** Angenommen

## Zweck

Freie, vorhersehbare Anordnung von Studio-Werkzeugen.

## Festlegungen

- Tool-Windows können an zulässige Zonen angedockt, gruppiert und als schwebende Fenster genutzt werden.
- Docking-Vorschauen zeigen das Ziel vor dem Ablegen.
- Ungültige Docking-Ziele werden abgewiesen; die bestehende Anordnung bleibt erhalten.

## Ergebnis

NPSPEC-STUDIO-DOCKING-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
