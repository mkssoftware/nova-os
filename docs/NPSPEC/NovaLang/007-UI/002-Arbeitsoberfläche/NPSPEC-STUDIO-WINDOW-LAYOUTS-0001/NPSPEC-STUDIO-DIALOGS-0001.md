# NPSPEC-STUDIO-DIALOGS-0001

**Status:** Angenommen

## Zweck

Einheitliche modale und nichtmodale Dialogführung.

## Festlegungen

- Dialoge übernehmen das NovaStudio-Design und verwenden systemweit konsistente Aktionen.
- Modalität wird nur für notwendige Entscheidungen eingesetzt.
- Standardaktion, Abbruch, Tastaturfokus und Fehlerhinweise sind eindeutig; irreversible Aktionen verlangen angemessene Bestätigung.

## Ergebnis

NPSPEC-STUDIO-DIALOGS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
