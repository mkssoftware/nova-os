# NPSPEC-STUDIO-WINDOW-LAYOUT-0001

**Status:** Angenommen

## Zweck

Grundstruktur des Studio-Hauptfensters.

## Festlegungen

- Das Hauptfenster gliedert sich in Titelbereich, Ribbon/Menübereich, Dokumentfläche, andockbare Werkzeugbereiche und Statusleiste.
- Die Dokumentfläche erhält bei Platzmangel Vorrang vor optionalen Werkzeugbereichen.
- Bereiche lassen sich skalieren, ohne Inhalte oder laufende Operationen zu verlieren.

## Ergebnis

NPSPEC-STUDIO-WINDOW-LAYOUT-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
