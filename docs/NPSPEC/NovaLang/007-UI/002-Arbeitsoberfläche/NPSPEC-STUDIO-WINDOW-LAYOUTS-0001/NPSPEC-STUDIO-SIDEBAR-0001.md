# NPSPEC-STUDIO-SIDEBAR-0001

**Status:** Angenommen

## Zweck

Schneller Zugriff auf zentrale Studio-Werkzeuge.

## Festlegungen

- Die Sidebar bietet direkten Zugriff auf häufig verwendete Ansichten und Funktionen.
- Aktive Einträge sind eindeutig markiert; Beschriftungen bleiben über Tooltip oder Text verfügbar.
- Bei Platzmangel kann die Sidebar kompakt dargestellt werden, ohne wesentliche Funktionen zu verstecken.

## Ergebnis

NPSPEC-STUDIO-SIDEBAR-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
