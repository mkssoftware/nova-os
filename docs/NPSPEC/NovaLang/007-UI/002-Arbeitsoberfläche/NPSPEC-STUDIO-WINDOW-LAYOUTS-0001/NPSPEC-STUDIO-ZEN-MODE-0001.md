# NPSPEC-STUDIO-ZEN-MODE-0001

**Status:** Angenommen

## Zweck

Konzentrierte Bearbeitung mit minimaler Oberfläche.

## Festlegungen

- Zen-Modus blendet nicht benötigte Panels, Ribbon und Statusbereiche temporär aus; die aktive Dokumentansicht steht im Mittelpunkt.
- Wesentliche Befehle bleiben über Tastatur, Commandbar oder bedarfsweise einblendbare Bedienelemente erreichbar.
- Beim Verlassen wird das vorherige Workspace-Layout unverändert wiederhergestellt.

## Ergebnis

NPSPEC-STUDIO-ZEN-MODE-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
