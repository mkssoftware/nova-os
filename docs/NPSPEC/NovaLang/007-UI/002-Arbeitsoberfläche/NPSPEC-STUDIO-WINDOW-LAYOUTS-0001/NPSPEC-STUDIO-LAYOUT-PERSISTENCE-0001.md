# NPSPEC-STUDIO-LAYOUT-PERSISTENCE-0001

**Status:** Angenommen

## Zweck

Wiederherstellung der Studio-Anordnung.

## Festlegungen

- Fensterpositionen, Docking-Struktur, Sichtbarkeit, Größen und aktives Workspace-Layout werden versioniert gespeichert.
- Persistenz erfolgt robust und darf keine Dokumentinhalte oder Zugangsdaten in Layoutdaten aufnehmen.
- Ungültige oder inkompatible Layoutdaten werden sicher auf ein nutzbares Standardlayout zurückgeführt.

## Ergebnis

NPSPEC-STUDIO-LAYOUT-PERSISTENCE-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
