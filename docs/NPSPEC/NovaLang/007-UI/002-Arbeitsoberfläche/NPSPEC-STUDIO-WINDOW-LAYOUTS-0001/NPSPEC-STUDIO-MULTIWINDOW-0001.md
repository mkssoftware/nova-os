# NPSPEC-STUDIO-MULTIWINDOW-0001

**Status:** Angenommen

## Zweck

Arbeiten mit mehreren Studio-Fenstern.

## Festlegungen

- Mehrere Hauptfenster können parallel genutzt werden und jeweils eigene Ansichten besitzen.
- Gemeinsam geöffnete Ressourcen erhalten konsistente Änderungs- und Konfliktbehandlung.
- Das Schließen eines Fensters beendet keine anderen Fenster oder Hintergrundoperationen ohne ausdrückliche Entscheidung.

## Ergebnis

NPSPEC-STUDIO-MULTIWINDOW-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
