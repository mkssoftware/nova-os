# NPSPEC-STUDIO-TABS-0001

**Status:** Angenommen

## Zweck

Einheitliche Registersteuerung für Studio-Bereiche.

## Festlegungen

- Tabs zeigen verständliche Namen und einen klaren Aktivzustand.
- Maus-, Tastatur- und Touchbedienung sowie Überlauf bei geringer Breite werden unterstützt.
- Tabwechsel verändern keine ungespeicherten Daten.

## Ergebnis

NPSPEC-STUDIO-TABS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
