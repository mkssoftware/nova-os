# NPSPEC-STUDIO-DOCUMENT-TABS-0001

**Status:** Angenommen

## Zweck

Navigation zwischen geöffneten Dokumenten.

## Festlegungen

- Dokument-Tabs zeigen Name, Dokumenttyp und ungespeicherte Änderungen.
- Tabs unterstützen Wechsel, Schließen, Neuordnung und kontextabhängige Aktionen.
- Vor dem Verwerfen ungespeicherter Änderungen erfolgt eine eindeutige Rückfrage.

## Ergebnis

NPSPEC-STUDIO-DOCUMENT-TABS-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
