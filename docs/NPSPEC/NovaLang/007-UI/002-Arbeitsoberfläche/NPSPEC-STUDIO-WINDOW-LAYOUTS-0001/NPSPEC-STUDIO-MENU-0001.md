# NPSPEC-STUDIO-MENU-0001

**Status:** Angenommen

## Zweck

Strukturierte Befehlsnavigation neben dem Ribbon.

## Festlegungen

- Das Ribbon ist der primäre sichtbare Befehlszugang; Menüs bündeln ergänzende und systematische Befehle.
- Befehle besitzen einheitliche IDs, Zustände und Tastaturzugänge, unabhängig vom Aufrufort.
- Regelmäßig genutzte Aktionen sind ohne tiefe Menüverschachtelung erreichbar.

## Ergebnis

NPSPEC-STUDIO-MENU-0001 definiert das verbindliche Verhalten dieses Studio-Bereichs.
