# NPSPEC-STUDIO-DARK-THEME-0001

**Status:** Angenommen

## Zweck

Dark-Design als Standarddarstellung des Studios.

## Festlegungen

- Das Standardtheme verwendet dunkle, neutrale Flächen mit gezielten blauen Akzenten.
- Editor, Logic Graph, Ribbon und Dialoge nutzen abgestufte Oberflächen statt durchgehend reinem Schwarz.
- Text, Symbole und Statusfarben bleiben bei allen unterstützten Zuständen lesbar.
- Das Dark-Theme funktioniert ohne Transparenz- oder GPU-Effekte.

## Ergebnis

Ein angenehmes, funktionales Standard-Dark-Theme.
