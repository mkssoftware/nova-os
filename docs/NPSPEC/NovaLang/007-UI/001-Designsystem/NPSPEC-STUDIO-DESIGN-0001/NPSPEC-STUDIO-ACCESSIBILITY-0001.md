# NPSPEC-STUDIO-ACCESSIBILITY-0001

**Status:** Angenommen

## Zweck

Barrierearme Nutzung aller Entwicklungsfunktionen.

## Festlegungen

- Texte und wichtige Bedienelemente erfüllen mindestens WCAG-2.2-AA-Kontrastanforderungen, soweit anwendbar.
- Befehle sind ohne Maus erreichbar; Ribbon, Dialoge und Logic Graph erhalten Tastaturwege.
- Steuerelemente besitzen zugängliche Namen, Rollen und Zustände; Statusmeldungen sind auslesbar.
- Skalierung, hoher Kontrast, reduzierte Bewegung und reduzierte Transparenz werden unterstützt.

## Ergebnis

Studio-Kernfunktionen bleiben für unterschiedliche Nutzungssituationen zugänglich.
