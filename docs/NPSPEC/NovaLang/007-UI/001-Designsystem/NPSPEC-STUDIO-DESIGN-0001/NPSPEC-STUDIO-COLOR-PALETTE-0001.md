# NPSPEC-STUDIO-COLOR-PALETTE-0001

**Status:** Angenommen

## Zweck

Semantische, konsistente Farbzuordnung.

## Festlegungen

- Farben werden über semantische Tokens wie Surface, Text, Accent, Border, Success, Warning und Error adressiert.
- Basisflächen bleiben neutral; Akzentfarben kennzeichnen Aktionen, Auswahl und gezielte Hervorhebungen.
- Logic-Graph-Porttypen erhalten stabile, unterscheidbare Farben; zusätzlich kennzeichnen Form oder Beschriftung ihren Typ.
- Kontrastvarianten sind zentral definiert; Komponenten dürfen keine frei eingebetteten Statusfarben verwenden.

## Ergebnis

Austauschbare Palette ohne widersprüchliche Farbbedeutungen.
