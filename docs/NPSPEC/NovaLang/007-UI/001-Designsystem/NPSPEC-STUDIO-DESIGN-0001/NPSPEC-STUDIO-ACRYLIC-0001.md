# NPSPEC-STUDIO-ACRYLIC-0001

**Status:** Angenommen

## Zweck

Kontrollierter Einsatz halbtransparenter Oberflächen.

## Festlegungen

- Acrylic ist auf geeignete Überlagerungen wie Menüs, Flyouts und ausgewählte Panels begrenzt.
- Editor-Text, Graph-Knoten und andere informationsdichte Arbeitsflächen besitzen ausreichend opake Hintergründe.
- Transparenz und Blur sind abschaltbar und respektieren Systemeinstellungen.
- Ohne Compositor-Unterstützung wird eine passende opake Hintergrundfarbe verwendet.

## Ergebnis

Atmosphärische Tiefenwirkung ohne Lesbarkeitsverlust.
