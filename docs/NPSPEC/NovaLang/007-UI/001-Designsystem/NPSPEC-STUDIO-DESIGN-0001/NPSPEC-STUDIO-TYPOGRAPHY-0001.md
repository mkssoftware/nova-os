# NPSPEC-STUDIO-TYPOGRAPHY-0001

**Status:** Angenommen

## Zweck

Klare Texthierarchie für produktive Entwicklungsarbeit.

## Festlegungen

- Ein zentral definierter Font-Stack besitzt zuverlässige Fallbacks.
- UI-Text und Quellcode nutzen getrennte Schriftrollen; Code erhält eine Monospace-Schrift.
- Schriftgrade, Zeilenhöhen und Gewichtungen basieren auf Typografie-Tokens.
- Ribbon-Titel, Panels, Tooltips und Fehlermeldungen bleiben auch bei Skalierung gut lesbar.

## Ergebnis

Einheitliche Typografie für Oberfläche, Code und Graph.
