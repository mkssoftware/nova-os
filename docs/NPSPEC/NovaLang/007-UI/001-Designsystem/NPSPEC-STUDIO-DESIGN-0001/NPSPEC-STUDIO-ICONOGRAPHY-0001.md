# NPSPEC-STUDIO-ICONOGRAPHY-0001

**Status:** Angenommen

## Zweck

Einheitliche, schnell erkennbare Bildsprache.

## Festlegungen

- Icons stammen aus einem konsistenten Vektorsatz mit definierten Größen und Strichstärken.
- Gleiche Operationen verwenden in Ribbon, Kontextmenü und Toolbar dieselben Symbole.
- Wichtige Befehle erhalten bei Bedarf ergänzende Textlabels; Bedeutung darf nicht nur aus Icons folgen.
- Icons passen sich Theme, Disabled-, Hover- und Fokuszuständen über Tokens an.

## Ergebnis

Wiedererkennbare Icons ohne Symbolwildwuchs.
