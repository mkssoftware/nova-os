# NPSPEC-STUDIO-SPACING-0001

**Status:** Angenommen

## Zweck

Systematische Abstände und ausbalancierte Informationsdichte.

## Festlegungen

- Abstände folgen einer zentralen, abgestuften Spacing-Skala.
- Ribbon-Gruppen, Dialoge, Panels und Graph-Inspektoren nutzen dieselbe Skala.
- Kompaktmodus reduziert Abstände, ohne Mindestbedienflächen für Eingaben zu unterschreiten.
- Ausrichtung folgt einem konsistenten Raster; unmotivierte Einzelabstände sind zu vermeiden.

## Ergebnis

Ruhige Anordnung bei produktiver Flächennutzung.
