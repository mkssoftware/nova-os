# NPSPEC-STUDIO-RIBBON-TOOLTIPS-0001

**Status:** Angenommen

## Zweck

Regelt präzise Befehlshilfen.

## Festlegungen

- Tooltips zeigen Befehlsname, knappe Wirkung und vorhandenes Tastaturkürzel.
- Bei deaktivierten Befehlen kann der Grund erläutert werden.
- Tooltips sind nicht der einzige Träger wesentlicher Informationen und verdecken keine fokussierten Controls dauerhaft.

## Ergebnis

Kontextbezogene Hilfe ohne zusätzliche Dialoge.
