# NPSPEC-STUDIO-RIBBON-SEARCH-0001

**Status:** Angenommen

## Zweck

Definiert die Befehlsuche im Studio.

## Festlegungen

- Suche findet Commands anhand von Name, Alias und Beschreibung.
- Treffer berücksichtigen Kontext und zeigen gesperrte oder nicht verfügbare Aktionen verständlich an.
- Ausführung verwendet ausschließlich die zentrale Command-Registry; die Suche umgeht keine Berechtigungen.

## Ergebnis

Schneller Zugriff auf auch selten genutzte Funktionen.
