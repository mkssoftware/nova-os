# NPSPEC-STUDIO-RIBBON-BUTTONS-0001

**Status:** Angenommen

## Zweck

Regelt einfache Ribbon-Schaltflächen.

## Festlegungen

- Buttons lösen genau einen registrierten Command aus.
- Icon und Kurzlabel kennzeichnen primäre Aktionen; Tooltips liefern Zusatzinformationen.
- Hover, Pressed, Focus, Disabled und Busy müssen unterscheidbar dargestellt werden.

## Ergebnis

Direkt verständliche Schaltflächen für Einzelaktionen.
