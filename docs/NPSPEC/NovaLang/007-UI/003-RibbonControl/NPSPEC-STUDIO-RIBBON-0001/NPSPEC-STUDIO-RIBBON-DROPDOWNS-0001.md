# NPSPEC-STUDIO-RIBBON-DROPDOWNS-0001

**Status:** Angenommen

## Zweck

Definiert Auswahllisten und Popup-Menüs.

## Festlegungen

- Dropdowns öffnen verankerte, innerhalb des Bildschirms begrenzte Popups.
- Einträge zeigen Auswahlzustand und Disabled-Zustand unabhängig an.
- Escape schließt ohne unbeabsichtigte Ausführung; Pfeiltasten navigieren.

## Ergebnis

Vorhersagbare Auswahlmenüs mit geringer Bedienlast.
