# NPSPEC-STUDIO-RIBBON-RESPONSIVE-0001

**Status:** Angenommen

## Zweck

Regelt das Verhalten bei begrenztem Fensterplatz.

## Festlegungen

- Controls reduzieren stufenweise von groß zu kompakt; Gruppen werden erst danach zusammengefasst.
- Priorisierte Befehle bleiben möglichst direkt erreichbar.
- Überlauf ist tastaturbedienbar, ohne Befehle funktional zu verlieren.

## Ergebnis

Nutzbares Ribbon auf kleinen und großen Arbeitsflächen.
