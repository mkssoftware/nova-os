# NPSPEC-STUDIO-RIBBON-COLLAPSE-0001

**Status:** Angenommen

## Zweck

Beschreibt das Minimieren der Ribbon-Fläche.

## Festlegungen

- Das Ribbon unterstützt erweitert, minimiert und temporär geöffnet.
- Im minimierten Zustand bleiben Tab-Auswahl und Quick Access erreichbar.
- Der Zustand wird pro Nutzer und Arbeitsbereich gespeichert.

## Ergebnis

Mehr Platz für Editor, Designer und Logic Graph bei erhaltenem Funktionszugriff.
