# NPSPEC-STUDIO-RIBBON-KEYTIPS-0001

**Status:** Angenommen

## Zweck

Definiert Tastaturhinweise nach Office-Vorbild.

## Festlegungen

- Per Alt wird ein KeyTip-Modus mit eindeutigen Zugriffscodes aktiviert.
- KeyTips führen über Tabs und Gruppen bis zum Command; Escape geht eine Ebene zurück.
- Codes sind innerhalb ihrer Ebene eindeutig und bei gegebener Konfiguration stabil.

## Ergebnis

Befehlszugriff über die Tastatur ohne Maus.
