# NPSPEC-STUDIO-RIBBON-EXTENSIONS-0001

**Status:** Angenommen

## Zweck

Regelt Erweiterungen des Ribbon durch Studio-Module.

## Festlegungen

- Erweiterungen registrieren Commands und deklarative Platzierungspunkte über versionierte Schnittstellen.
- Command-IDs sind namespaced; Kollisionen und nicht unterstützte Versionen werden abgewiesen.
- Erweiterungen erhalten keine weitergehenden Capabilities durch ihre Ribbon-Platzierung.

## Ergebnis

Sicher erweiterbare Bedienoberfläche ohne Bruch der Kernstruktur.
