# NPSPEC-STUDIO-RIBBON-STATE-0001

**Status:** Angenommen

## Zweck

Definiert konsistente UI-Zustände und deren Aktualisierung.

## Festlegungen

- Ribbon-Zustände werden aus aktivem Dokument, Auswahl, Modus, Ausführungsstatus und Berechtigungen abgeleitet.
- Zustandsupdates erfolgen ereignisgesteuert und atomar pro UI-Update.
- Disabled, Hidden, Selected und Busy werden nicht miteinander gleichgesetzt.

## Ergebnis

Eine jederzeit zum tatsächlichen Studio-Kontext passende Oberfläche.
