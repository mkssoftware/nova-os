# NPSPEC-STUDIO-RIBBON-QUICKACCESS-0001

**Status:** Angenommen

## Zweck

Spezifiziert die Schnellzugriffsleiste.

## Festlegungen

- Häufige Commands lassen sich unabhängig vom aktiven Ribbon-Tab anheften.

- Anordnung wird benutzerbezogen persistent gespeichert und kann zurückgesetzt werden.
