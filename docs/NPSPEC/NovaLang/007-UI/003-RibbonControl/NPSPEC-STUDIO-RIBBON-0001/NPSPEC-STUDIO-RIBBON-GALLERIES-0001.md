# NPSPEC-STUDIO-RIBBON-GALLERIES-0001

**Status:** Angenommen

## Zweck

Regelt visuelle Optionen im Ribbon.

## Festlegungen

- Galerien präsentieren eine begrenzte Auswahl als Vorschauraster, etwa Themes oder UI-Komponenten.
- Jeder Eintrag hat eine textuelle Alternative und einen definierten Auswahlwert.
- Vorschauänderungen sind reversibel; Übernahme erfolgt als expliziter Command.

## Ergebnis

Schnelle visuelle Auswahl ohne unkontrollierte Zustandsänderungen.
