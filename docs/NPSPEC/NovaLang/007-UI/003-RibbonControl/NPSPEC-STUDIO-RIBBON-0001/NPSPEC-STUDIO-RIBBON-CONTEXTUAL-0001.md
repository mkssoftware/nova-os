# NPSPEC-STUDIO-RIBBON-CONTEXTUAL-0001

**Status:** Angenommen

## Zweck

Legt kontextabhängige Ribbon-Tabs fest.

## Festlegungen

- Kontext-Tabs erscheinen bei passender Auswahl oder aktivem Arbeitsmodus, etwa Node, UI-Element oder Debugging.
- Kontext-Tabs sind optisch gekennzeichnet und verschwinden mit ihrem Kontext.
- Wechsel darf keine ungespeicherten Änderungen verwerfen oder Befehle auf einen veralteten Kontext anwenden.

## Ergebnis

Relevante Funktionen werden eingeblendet, ohne die Grundnavigation umzubauen.
