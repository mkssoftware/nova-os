# NPSPEC-STUDIO-RIBBON-0001

**Status:** Angenommen

## Zweck

Definiert die Office-inspirierte Ribbon-Bedienung von NovaLang Studio.

## Festlegungen

- Das Ribbon stellt häufig verwendete Aktionen ohne tiefe Menüwege bereit.
- Tabs ordnen Befehle nach Aufgaben; kontextabhängige Tabs ergänzen die Grundansicht.
- Codeeditor, UI-Designer und Logic Graph nutzen dieselben Bedienregeln.
- Das Ribbon verwendet das NovaStudio-Dark-Design und bleibt vollständig tastaturbedienbar.

## Ergebnis

Ein einheitliches, aufgabenorientiertes Ribbon als primärer Befehlszugang.
