# NPSPEC-STUDIO-GRAPH-PERFORMANCE-0001

**Status:** Angenommen

## Zweck
Performance-Diagnose pro Graph-Element.

## Festlegungen
- Erfasst optional Ausführungshäufigkeit, Laufzeit und Wartezeit pro Knoten bzw. Pfad mit ausgewiesener Messgrundlage.
- Profiling-Overhead und Stichproben sind sichtbar; Zahlen werden nicht als präzise ausgegeben, wenn nur Schätzungen vorliegen. Messungen erzeugen keine zusätzlichen Rechte.
- Debug-Daten sind von der produktiven Ausführung getrennt; Capability-Grenzen und Isolation bleiben wirksam.

## Ergebnis
Engpässe im Logic Graph sind messbar.
