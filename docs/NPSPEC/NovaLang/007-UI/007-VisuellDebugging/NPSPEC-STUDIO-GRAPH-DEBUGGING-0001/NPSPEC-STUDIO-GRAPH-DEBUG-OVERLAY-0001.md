# NPSPEC-STUDIO-GRAPH-DEBUG-OVERLAY-0001

**Status:** Angenommen

## Zweck
Einblendbare Debug-Informationen.

## Festlegungen
- Ein separates Overlay bündelt Ausführungsmarkierungen, Breakpoints, Live-Werte und Performance-Indikatoren auf dem Canvas.
- Ebenen lassen sich einzeln schalten; Zoom und Selektion bleiben bedienbar. Das Overlay verändert weder gespeicherte Knotenpositionen noch die zugrunde liegende Graph-Datei.
- Debug-Daten sind von der produktiven Ausführung getrennt; Capability-Grenzen und Isolation bleiben wirksam.

## Ergebnis
Diagnosedaten erscheinen kontextbezogen ohne Layout-Eingriff.
