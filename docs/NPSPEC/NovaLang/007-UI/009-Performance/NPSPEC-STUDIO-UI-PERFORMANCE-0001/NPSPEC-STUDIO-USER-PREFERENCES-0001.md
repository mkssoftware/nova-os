# NPSPEC-STUDIO-USER-PREFERENCES-0001

**Status:** Angenommen

## Zweck
Persistente Nutzereinstellungen.

## Festlegungen
- Darstellung, Eingabe, Ribbon, Arbeitsbereich und Performance-Optionen sind pro Benutzer getrennt zu speichern.
- Einstellungen müssen versioniert, validiert und bei Migrationen rückwärtsverträglich behandelt werden.
- Projektbezogene Einstellungen sind klar von globalen Nutzerpräferenzen zu trennen.
- Defekte oder unbekannte Werte dürfen den Start nicht verhindern; sichere Standardwerte greifen.

## Ergebnis
Persönliche Arbeitsweisen bleiben über Sitzungen hinweg erhalten.
