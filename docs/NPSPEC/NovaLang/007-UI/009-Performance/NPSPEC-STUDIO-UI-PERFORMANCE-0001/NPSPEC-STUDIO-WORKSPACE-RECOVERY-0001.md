# NPSPEC-STUDIO-WORKSPACE-RECOVERY-0001

**Status:** Angenommen

## Zweck
Wiederherstellung beschädigter Arbeitsbereiche.

## Festlegungen
- Defekte Layoutzustände dürfen Studio und Projekte nicht unbenutzbar machen.
- Ein sicherer Startmodus muss Panels, Docking und Fenstereinstellungen auf gültige Defaults zurücksetzen können.
- Wiederherstellung muss zwischen Layoutfehlern, Autosave-Daten und Projektfehlern unterscheiden.
- Reparaturen benötigen nachvollziehbare Diagnosen und dürfen Originaldaten nicht stillschweigend löschen.

## Ergebnis
Arbeitsbereiche lassen sich nach Fehlern kontrolliert reparieren.
