# NPSPEC-STUDIO-COMMAND-PALETTE-0001

**Status:** Angenommen

## Zweck
Zentrale Befehlssuche im Studio.

## Festlegungen
- Eine über Tastatur aufrufbare Befehlspalette muss Ribbon-Aktionen, Navigation und Editorbefehle gemeinsam durchsuchen.
- Treffer müssen nach Text, Kontext und verfügbarer Berechtigung gefiltert werden.
- Befehle verwenden die zentrale Command-Registry; die Palette führt keine Sonderimplementierungen aus.
- Nicht verfügbare Befehle werden verständlich begründet statt stillschweigend ausgeführt.

## Ergebnis
Häufige Aufgaben sind ohne Menüsuche erreichbar.
