# NPSPEC-STUDIO-SESSION-RESTORE-0001

**Status:** Angenommen

## Zweck
Wiederaufnahme der letzten Studio-Sitzung.

## Festlegungen
- Geöffnete Projekte, Dokumente, Editorzustände, aktive Tabs und Fensteranordnung sollen wiederherstellbar sein.
- Der Sitzungszustand ist unabhängig von den eigentlichen Projektdateien zu speichern.
- Fehlende Dateien oder Monitore werden erkannt und ohne Blockade des Starts behandelt.
- Nach ungewöhnlicher Beendigung muss eine kontrollierte Wiederherstellung mit Wahlmöglichkeit angeboten werden.

## Ergebnis
Der vorherige Arbeitskontext kann sicher wiederaufgenommen werden.
