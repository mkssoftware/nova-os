# NPSPEC-STUDIO-UI-VIRTUALIZATION-0001

**Status:** Angenommen

## Zweck
Virtualisierte UI-Listen und Ansichten.

## Festlegungen
- Projektbaum, Suchtreffer, Logs, Eigenschaftenlisten und Capability-Katalog müssen bei großen Datenmengen sichtbereichsbasiert rendern.
- Nicht sichtbare Einträge dürfen keine dauerhaften UI-Objekte benötigen.
- Selektion, Tastaturfokus, Scrollposition und Barrierefreiheit müssen trotz Virtualisierung erhalten bleiben.
- Datenänderungen dürfen nicht die gesamte Liste neu aufbauen.

## Ergebnis
Große Datenbestände bleiben schnell navigierbar.
