# NPSPEC-STUDIO-KEYBOARD-NAVIGATION-0001

**Status:** Angenommen

## Zweck
Vollständige Tastaturbedienung.

## Festlegungen
- Ribbon, Toolfenster, Dokument-Tabs, Dialoge und Graph-Canvas müssen ohne Maus bedienbar sein.
- Fokuswechsel müssen sichtbar, vorhersagbar und nach Schließen temporärer Oberflächen rückführbar sein.
- Tastaturkürzel dürfen sich nicht unbemerkt überschreiben; Nutzeranpassungen müssen prüfbar sein.
- Aktionen zum Verbinden und Auswählen von Graphknoten benötigen tastaturgesteuerte Alternativen.

## Ergebnis
Das Studio ist konsistent und effizient per Tastatur steuerbar.
