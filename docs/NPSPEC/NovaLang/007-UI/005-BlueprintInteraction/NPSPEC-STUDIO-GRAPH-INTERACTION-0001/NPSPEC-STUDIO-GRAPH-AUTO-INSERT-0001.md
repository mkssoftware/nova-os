# NPSPEC-STUDIO-GRAPH-AUTO-INSERT-0001

**Status:** Angenommen

## Zweck

Knoten in Leitungen einsetzen für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Wird ein kompatibler Knoten auf eine Leitung gezogen, zeigt eine Vorschau die Auftrennung und die neuen Anschlüsse.
- Einfügen erfolgt nur bei eindeutiger Typ- und Richtungszuordnung und als einzelne Undo-Transaktion.
- Bei inkompatiblen Pins wird die bestehende Leitung unverändert erhalten.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere knoten in leitungen einsetzen im Logic Graph.
