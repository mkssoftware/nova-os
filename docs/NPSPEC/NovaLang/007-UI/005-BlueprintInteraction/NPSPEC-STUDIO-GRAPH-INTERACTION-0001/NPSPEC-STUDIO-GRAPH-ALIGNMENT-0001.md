# NPSPEC-STUDIO-GRAPH-ALIGNMENT-0001

**Status:** Angenommen

## Zweck

Ausrichten und verteilen für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Mehrfachauswahl unterstützt Ausrichten an Kanten/Mitten sowie gleichmäßiges horizontales und vertikales Verteilen.
- Ein Referenzknoten beziehungsweise die gemeinsame Auswahlbox definiert die Operation eindeutig.
- Ausrichten verändert keine Verbindungen oder Ausführungsreihenfolge und ist rückgängig machbar.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere ausrichten und verteilen im Logic Graph.
