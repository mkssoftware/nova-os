# NPSPEC-STUDIO-GRAPH-AUTO-LAYOUT-0001

**Status:** Angenommen

## Zweck

Automatische Anordnung für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Auto-Layout ordnet markierte Teilgraphen oder den Gesamtgraph anhand des Kontroll- und Datenflusses an.
- Das Verfahren reduziert Kreuzungen, wahrt Gruppen- und Kommentarzusammenhänge und respektiert fixierte Knoten.
- Eine Vorschau sowie eine einzelne Undo-Transaktion ermöglichen verlustfreies Zurücksetzen; Graphsemantik bleibt unverändert.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere automatische anordnung im Logic Graph.
