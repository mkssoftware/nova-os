# NPSPEC-STUDIO-GRAPH-NODE-SEARCH-0001

**Status:** Angenommen

## Zweck

Knotensuche für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Die Suche findet Knoten nach Anzeigename, Capability-ID, Kategorie und Suchbegriffen.
- Suchergebnisse sind nach Graphkontext und Pin-Kompatibilität priorisiert; nicht erlaubte Knoten sind klar gekennzeichnet.
- Tastatur-Navigation, Vorschau und Einfügen ohne Maus müssen möglich sein.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere knotensuche im Logic Graph.
