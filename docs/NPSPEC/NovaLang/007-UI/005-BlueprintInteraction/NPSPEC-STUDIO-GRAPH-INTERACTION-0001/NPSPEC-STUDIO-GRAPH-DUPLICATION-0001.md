# NPSPEC-STUDIO-GRAPH-DUPLICATION-0001

**Status:** Angenommen

## Zweck

Knoten duplizieren für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Duplizieren erzeugt neue Instanz-IDs, bewahrt Eigenschaften und interne Verbindungen der Auswahl.
- Die Kopie wird sichtbar versetzt abgelegt und bleibt ausgewählt.
- Referenzen auf externe Ressourcen und Capability-Berechtigungen werden nicht als neue Autorisierung interpretiert.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere knoten duplizieren im Logic Graph.
