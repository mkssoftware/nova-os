# NPSPEC-STUDIO-GRAPH-COLLAPSE-0001

**Status:** Angenommen

## Zweck

Untergraphen einklappen für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Ausgewählte zusammenhängende Knoten können zu einem benannten, wieder aufklappbaren Untergraphen zusammengefasst werden.
- Ein- und Ausgangsschnittstellen entsprechen den bisherigen externen Verbindungen und erhalten deren Typ- und Capability-Verträge.
- Einklappen darf Ausführungssemantik nicht verändern; Navigation zum Original-Untergraphen bleibt möglich.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere untergraphen einklappen im Logic Graph.
