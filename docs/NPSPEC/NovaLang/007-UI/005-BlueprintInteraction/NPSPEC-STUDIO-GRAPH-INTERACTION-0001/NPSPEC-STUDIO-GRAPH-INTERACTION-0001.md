# NPSPEC-STUDIO-GRAPH-INTERACTION-0001

**Status:** Angenommen

## Zweck

Interaktionsmodell für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Graphbearbeitung erfolgt über konsistente Maus-, Touchpad- und Tastaturaktionen; die gleiche Aktion muss rückgängig gemacht werden können, sofern sie das Modell verändert.
- Canvas-Navigation, Knotenauswahl und Verbindungsbearbeitung besitzen eindeutige Gesten; aktive Werkzeuge und temporäre Modi werden sichtbar angezeigt.
- Nur validierte Modelländerungen werden übernommen; Abbrechen mit Esc verwirft Vorschauänderungen ohne Seiteneffekte.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere interaktionsmodell im Logic Graph.
