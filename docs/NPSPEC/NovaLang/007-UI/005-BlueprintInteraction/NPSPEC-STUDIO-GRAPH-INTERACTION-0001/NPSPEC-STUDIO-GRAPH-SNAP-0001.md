# NPSPEC-STUDIO-GRAPH-SNAP-0001

**Status:** Angenommen

## Zweck

Rasterfang für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Knoten können beim Verschieben und Erstellen an einem konfigurierbaren Raster einrasten.
- Snap lässt sich temporär deaktivieren; die visuelle Rasteranzeige und die Fanglogik bleiben getrennt.
- Snap verändert ausschließlich Layoutkoordinaten, niemals Pin-Typen oder Ausführungslogik.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere rasterfang im Logic Graph.
