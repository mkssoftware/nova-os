# NPSPEC-STUDIO-GRAPH-AUTO-CONNECTION-0001

**Status:** Angenommen

## Zweck

Automatische Verbindung für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Beim Platzieren eines Knotens ausgehend von einem Pin wird eine kompatible Verbindung angeboten.
- Die automatische Auswahl berücksichtigt Pinrichtung, NovaLang-Datentyp, Kontrollfluss und Capability-Verträge; Mehrdeutigkeiten erfordern Auswahl.
- Kein implizites Einfügen sicherheitsrelevanter Capabilities oder stillschweigendes Erteilen von Berechtigungen.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere automatische verbindung im Logic Graph.
