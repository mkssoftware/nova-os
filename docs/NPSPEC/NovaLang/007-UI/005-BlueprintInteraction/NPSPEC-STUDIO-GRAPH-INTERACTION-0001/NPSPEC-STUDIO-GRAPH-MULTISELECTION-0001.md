# NPSPEC-STUDIO-GRAPH-MULTISELECTION-0001

**Status:** Angenommen

## Zweck

Mehrfachauswahl für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Shift-Klick erweitert oder reduziert eine vorhandene Auswahl; Rechteckauswahl markiert vollständig oder per Modus geschnittene Knoten.
- Mehrfach ausgewählte Knoten werden gemeinsam verschoben, dupliziert, ausgerichtet oder gelöscht.
- Auswahlzustand wird visuell eindeutig und unabhängig vom Fokus dargestellt; Esc hebt die Auswahl auf, sofern keine aktive Operation abzubrechen ist.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere mehrfachauswahl im Logic Graph.
