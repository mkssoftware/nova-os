# NPSPEC-STUDIO-GRAPH-WIRE-REROUTING-0001

**Status:** Angenommen

## Zweck

Leitungen umverbinden für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Das Ziehen eines verbundenen Endpunkts ermöglicht die Neuzuordnung zu einem anderen Pin.
- Die ursprüngliche Verbindung bleibt bis zum gültigen Abschluss erhalten; Esc stellt den Ausgangszustand wieder her.
- Typprüfung, Kardinalität und Capability-Policy gelten identisch wie beim Neuanlegen von Leitungen.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere leitungen umverbinden im Logic Graph.
