# NPSPEC-STUDIO-GRAPH-CONTEXT-SENSITIVE-0001

**Status:** Angenommen

## Zweck

Kontextsensitive Werkzeuge für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Aktive Selektion, Pin-Typ, Dokumentmodus und Capability-Rechte bestimmen sichtbare und nutzbare Aktionen.
- Kontextwechsel aktualisieren Suchvorschläge, Menüs und Ribbon ohne zeitverzögerte Fehlbefehle.
- Das Filtern darf notwendige Diagnosen, Berechtigungsinformationen oder eine Möglichkeit zum Anzeigen aller Knoten nicht verbergen.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere kontextsensitive werkzeuge im Logic Graph.
