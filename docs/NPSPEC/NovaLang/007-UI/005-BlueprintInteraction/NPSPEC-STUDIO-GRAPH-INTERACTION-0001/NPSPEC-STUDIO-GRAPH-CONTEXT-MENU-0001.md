# NPSPEC-STUDIO-GRAPH-CONTEXT-MENU-0001

**Status:** Angenommen

## Zweck

Kontextmenü für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Rechtsklick auf Canvas, Knoten, Pin oder Leitung öffnet ein jeweils passendes Menü.
- Menüeinträge verwenden denselben zentralen Command-Handler wie Ribbon und Tastaturkürzel.
- Deaktivierte Befehle bleiben erklärbar; destruktive Operationen berücksichtigen Undo und gegebenenfalls Bestätigung.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere kontextmenü im Logic Graph.
