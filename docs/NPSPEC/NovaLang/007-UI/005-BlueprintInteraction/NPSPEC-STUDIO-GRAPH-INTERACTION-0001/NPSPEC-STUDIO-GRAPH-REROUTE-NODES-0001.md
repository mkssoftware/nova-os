# NPSPEC-STUDIO-GRAPH-REROUTE-NODES-0001

**Status:** Angenommen

## Zweck

Leitungsführungspunkte für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Reroute-Knoten lenken Leitungen ohne Ausführungs- oder Datensemantik um.
- Sie können eingefügt, verschoben und entfernt werden; das Entfernen erhält die logische Verbindung.
- Ihre Position wird im Layout gespeichert und bei Copy/Paste samt Verbindungen berücksichtigt.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere leitungsführungspunkte im Logic Graph.
