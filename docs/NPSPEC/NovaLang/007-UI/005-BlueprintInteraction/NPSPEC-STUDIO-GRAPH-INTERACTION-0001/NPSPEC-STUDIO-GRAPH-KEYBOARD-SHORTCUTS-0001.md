# NPSPEC-STUDIO-GRAPH-KEYBOARD-SHORTCUTS-0001

**Status:** Angenommen

## Zweck

Tastaturbedienung für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Standardaktionen wie Löschen, Kopieren, Einfügen, Rückgängig und Wiederholen verwenden systemweit konsistente Shortcuts.
- Alle wesentlichen Graphaktionen einschließlich Suche, Zoom, Fokuswechsel und Verbindungsbearbeitung sind per Tastatur zugänglich.
- Konflikte zwischen Studio-, Editor- und Graph-Shortcuts werden kontextbezogen aufgelöst; Belegungen sind einsehbar.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere tastaturbedienung im Logic Graph.
