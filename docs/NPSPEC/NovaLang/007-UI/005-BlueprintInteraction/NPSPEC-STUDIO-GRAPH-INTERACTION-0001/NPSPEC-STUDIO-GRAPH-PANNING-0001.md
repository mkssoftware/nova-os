# NPSPEC-STUDIO-GRAPH-PANNING-0001

**Status:** Angenommen

## Zweck

Canvas verschieben für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Mittlere Maustaste ziehen verschiebt die Ansicht, ohne Knotenpositionen zu verändern.
- Leertaste + linke Maustaste ziehen bietet eine alternative Pan-Geste; aktive Verbindungs- oder Drag-Aktionen werden dadurch nicht unbemerkt ausgelöst.
- Panning erhält Zoomstufe und Graphkoordinaten; der Viewport wird unabhängig vom Graphmodell gespeichert.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere canvas verschieben im Logic Graph.
