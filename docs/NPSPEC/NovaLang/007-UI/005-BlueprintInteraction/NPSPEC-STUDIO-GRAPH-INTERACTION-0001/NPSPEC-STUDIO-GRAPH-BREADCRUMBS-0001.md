# NPSPEC-STUDIO-GRAPH-BREADCRUMBS-0001

**Status:** Angenommen

## Zweck

Navigationspfad für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Breadcrumbs zeigen Solution, Graph und verschachtelte Untergraphen in ihrer Hierarchie.
- Jede Ebene ist direkt anwählbar; Zurücknavigation bewahrt Auswahl und Viewport, soweit möglich.
- Pfadangaben verwenden stabile IDs intern und lesbare Namen in der Oberfläche; Umbenennungen brechen die Navigation nicht.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere navigationspfad im Logic Graph.
