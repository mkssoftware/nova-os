# NPSPEC-STUDIO-GRAPH-ZOOMING-0001

**Status:** Angenommen

## Zweck

Zoomsteuerung für den NovaLang Studio Logic Graph festlegen.

## Festlegungen

- Mausrad mit Strg zoomt um die Zeigerposition; Zoom-Bedienelemente und Tastaturbefehle bieten die gleiche Funktion.
- Zoom ist stufenlos innerhalb konfigurierbarer, begrenzter Min-/Max-Werte; die Darstellung wechselt bei geringer Vergrößerung zu reduzierten Details.
- Zoom auf Auswahl und Zoom auf Gesamtgraph sind direkte Aktionen; Zoom ändert keine Modellkoordinaten.

## Ergebnis

Eine einheitliche, nachvollziehbare und für NovaLang sowie das Capability-Modell sichere zoomsteuerung im Logic Graph.
