# NPSPEC-STUDIO-GRAPH-CANVAS-STYLE-0001

**Status:** Angenommen

## Zweck
Darstellung der Zeichenfläche.

## Festlegungen
- Die Zeichenfläche ist eine ruhige, dunkle und theoretisch unbegrenzte 2D-Arbeitsfläche mit Pan und Zoom.
- Hintergrund und Grid dominieren keine Nodes; Koordinaten bleiben beim Zoomen stabil und Inhalte werden nicht unbeabsichtigt verschoben.

## Ergebnis
Ein zuverlässiger Arbeitsbereich für kleine und große Graphen.
