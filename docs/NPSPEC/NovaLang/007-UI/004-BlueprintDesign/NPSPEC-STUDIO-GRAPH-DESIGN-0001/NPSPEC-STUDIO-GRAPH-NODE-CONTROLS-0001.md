# NPSPEC-STUDIO-GRAPH-NODE-CONTROLS-0001

**Status:** Angenommen

## Zweck
Bedienelemente innerhalb von Nodes.

## Festlegungen
- Nodes dürfen passende Inline-Controls für konstante Werte und erlaubte Parameter bereitstellen.
- Controls folgen NovaStudio-Design-Tokens, unterstützen Tastatur und verändern keine Graph-Verkabelung unbemerkt; Script-Systemzugriffe erfolgen ausschließlich über vorgeschaltete Capability-Nodes.

## Ergebnis
Parameter können direkt und kontrolliert bearbeitet werden.
