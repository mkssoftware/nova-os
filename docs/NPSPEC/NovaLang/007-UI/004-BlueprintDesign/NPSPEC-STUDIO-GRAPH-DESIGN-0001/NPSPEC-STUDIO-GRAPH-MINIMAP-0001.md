# NPSPEC-STUDIO-GRAPH-MINIMAP-0001

**Status:** Angenommen

## Zweck
Miniatur-Navigation.

## Festlegungen
- Eine zuschaltbare Minimap zeigt Graphausdehnung, aktuelle Viewport-Position und grobe Gruppenstruktur.
- Navigation per Klick/Drag verändert nur den Viewport; Inhalte bleiben bei großen Graphen performant abstrahiert.

## Ergebnis
Schneller Überblick und Navigation.
