# NPSPEC-STUDIO-GRAPH-REGIONS-0001

**Status:** Angenommen

## Zweck
Zusammenfassende Graphbereiche.

## Festlegungen
- Visuelle Regionen fassen zusammengehörige Nodes als benannte Bereiche mit Hintergrund und optionaler Markierung zusammen.
- Regionen sind reine Organisationsobjekte; gemeinsames Verschieben ist explizit und verändert keine Verbindungen oder Berechtigungen.

## Ergebnis
Übersichtliche Strukturierung umfangreicher Abläufe.
