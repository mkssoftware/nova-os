# NPSPEC-STUDIO-GRAPH-OVERVIEW-0001

**Status:** Angenommen

## Zweck
Gesamtübersicht und Navigation.

## Festlegungen
- Der Editor bietet Auf Gesamtgraph zoomen, Auswahl einpassen und Zur Auswahl springen.
- Befehle sind über Ribbon, Tastatur und Suche verfügbar; sie verändern weder Node-Koordinaten noch Ausführungslogik.

## Ergebnis
Effiziente Navigation unabhängig von Graphgröße.
