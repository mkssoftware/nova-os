# NPSPEC-STUDIO-GRAPH-WIRE-ANIMATIONS-0001

**Status:** Angenommen

## Zweck
Bewegung entlang von Verbindungen.

## Festlegungen
- Optionale, sparsame Animationen visualisieren aktive Ausführung und Datenfluss im Diagnosemodus.
- Animationen zeigen tatsächliche Runtime-Ereignisse, niemals erfundene Aktivität; bei reduzierter Bewegung und niedriger Leistung werden sie deaktiviert.

## Ergebnis
Nachvollziehbare Diagnose ohne unnötige GPU-Last.
