# NPSPEC-STUDIO-GRAPH-DARK-THEME-0001

**Status:** Angenommen

## Zweck
Dunkles Graph-Design.

## Festlegungen
- Der Graph verwendet ein dunkles, kontrastkontrolliertes Standardthema mit zurückhaltenden Akzentfarben.
- Texte, Ports, Auswahl und Fehlermeldungen bleiben klar unterscheidbar; System- und Barrierefreiheitseinstellungen haben Vorrang.

## Ergebnis
Ein augenschonender und lesbarer Graph auch bei großen Projekten.
