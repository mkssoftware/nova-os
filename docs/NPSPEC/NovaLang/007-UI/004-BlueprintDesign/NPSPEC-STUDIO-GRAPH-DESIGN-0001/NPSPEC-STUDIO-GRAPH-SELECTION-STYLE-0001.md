# NPSPEC-STUDIO-GRAPH-SELECTION-STYLE-0001

**Status:** Angenommen

## Zweck
Darstellung von Auswahlzuständen.

## Festlegungen
- Ausgewählte Nodes, Pins, Leitungen und Gruppen sind visuell eindeutig hervorgehoben.
- Mehrfachauswahl, Tastaturfokus und Hover bleiben unterschiedlich; Auswahlrahmen verdecken Inhalte nicht.

## Ergebnis
Eindeutige Auswahl auch in dichten Graphen.
