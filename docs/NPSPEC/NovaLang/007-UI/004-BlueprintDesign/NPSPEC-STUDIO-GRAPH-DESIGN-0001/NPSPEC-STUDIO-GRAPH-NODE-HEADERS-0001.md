# NPSPEC-STUDIO-GRAPH-NODE-HEADERS-0001

**Status:** Angenommen

## Zweck
Kopfbereich von Nodes.

## Festlegungen
- Jeder Node-Header enthält einen klaren Titel und optional Kategorie-Icon oder Zustandsindikator.
- Header dient als primäre Drag-Fläche; Status und Fehlermeldungen dürfen den Titel nicht unlesbar machen.

## Ergebnis
Schnelle Orientierung und sichere Interaktion.
